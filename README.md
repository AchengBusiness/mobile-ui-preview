# Mobile UI Preview Tool

A lightweight, single-file mobile UI component preview and screenshot toolkit. Built for designers and developers who need quick mobile interface mockups.

## Features

- Multiple platform UI component previews
- Real-time editing with live preview
- High-resolution screenshot export (3x)
- PWA support - works offline
- LocalStorage data persistence
- Responsive design for all screen sizes

## Usage

Simply open `index.html` in any modern browser, or visit the [live demo](https://achengbusiness.github.io/mobile-ui-preview/).

## Tech Stack

- Vanilla HTML/CSS/JavaScript (zero dependencies)
- html2canvas for screenshot export
- Service Worker for offline caching
- PWA manifest for installability
